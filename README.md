# Подборка для Кладоискателей (MVP)

## Запуск

```bash
npm install
npm run prisma:generate
npm run dev
```

## Переменные окружения

Создайте `.env` на основе `.env.example`.

## Структура
- `app/` — страницы и API (App Router)
- `components/` — UI-компоненты
- `prisma/` — схема БД
- `docs/` — продуктовая и техническая документация

## Основной функционал MVP
- Лендинг и страницы сервиса
- Карта (демо-выбор региона)
- Калькулятор цены (700 ₽/место, минимум 7)
- Оформление заказа → запись в БД
- Кабинет с заказами
- Админка для добавления мест
- Генерация PDF
