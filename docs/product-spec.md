# Продуктовая концепция: «Подборка для Кладоискателей»

## 1) Позиционирование и УТП
**Кому:**
- Историко-краеведческие исследователи, коллекционеры, любители локальной истории.
- Клиенты, которым нужны архивные справки по районам России.

**Боли клиента:**
- Нет доступа к закрытым архивным фондам.
- Сложно понять, где искать материалы и как структурировать информацию.
- Нужен безопасный и легальный формат без «серых» инструкций.

**УТП:**
- Профессиональный архивный ресерч с верификацией источников.
- Полная структурированная справка из 10 разделов.
- Контроль выдачи: личный кабинет + PDF с водяным знаком и лимитами.

**Почему можно доверять:**
- Прозрачные источники, понятная структура отчета.
- Юридически корректные формулировки: историко-краеведческое исследование.
- Прозрачные сроки (24–72 часа) и фиксированная цена 700 ₽/место.

## 2) Структура сайта и пользовательские сценарии

**Sitemap (MVP + v1):**
- Главная (лендинг)
- Как это работает
- Тарифы + калькулятор
- Карта (выбор региона/зоны)
- Оформление заказа
- Оплата / статусы
- Личный кабинет
  - Заказы
  - Карточки мест
  - Поиск и фильтры
- Карточка места
- FAQ / поддержка
- Политика / оферта / конфиденциальность
- Админ-панель

**User flows:**
1) Гость → выбор района на карте → расчет цены → оформление заказа → оплата → личный кабинет → получение мест.
2) Повторный заказ: кабинет → новый заказ → оплата → пополнение списка.
3) Поддержка: любой экран → FAQ → обращение в поддержку.

**Калькулятор**

### «Как это работает»
- 4 шага: выбор района → заказ → оплата → выдача
- Блок «Безопасный формат» (без инструкций к незаконным действиям)

### Тарифы/калькулятор

- Форма: регион, количество мест (мин. 7), контакты

### FAQ/поддержка

### Политика/оферта/конфиденциальность

## 4) Функциональные и нефункциональные требования

**Функциональные:**
- Выбор региона/зоны
- Калькулятор (700 ₽/место, минимум 7)
- Оформление заказа
- Оплата и статусы
- Кабинет с карточками мест
- PDF с водяным знаком

**Нефункциональные:**
- Производительность: TTFB < 500 ms, LCP < 2.5 s
- Безопасность: защита API, защита контента
- Контроль выгрузок: лимит скачиваний
- Watermark PDF
- Логирование и резервные копии

## 5) Роли и доступы
- **Клиент:** просмотр своих заказов/карт/карточек, скачивание PDF.
- **Админ:** управление местами, заказами, выдачей.
- **Менеджер (опционально):** общение, статусы, проверка оплат.

## 6) Админ-панель
- CRUD мест
- Загрузка медиа и документов
- Привязка к координатам
- Управление заказами и статусами

## 7) Данные и модели (ERD текстом)
- Users (id, email, role)
- Orders (id, userId, status, totalPrice, placesCount)
- OrderItems (orderId, placeId, price)
- Payments (orderId, provider, status, amount)
- Regions (id, name, parentId)
- PlaceReports (placeId + 10 полей отчета)
- Files (placeId, type, url)
- AuditLogs (userId, action, meta)

## 8) Карта
- Интерактивная карта РФ
- Сначала выбор региона, затем зоны/муниципалитета
- До оплаты скрываем точки
- После оплаты — показ точек и карточек

## 9) Платежи (Россия)
- ЮKassa, CloudPayments, Robokassa
- Чеки: автоматические фискальные чеки (ФЗ-54) через провайдера
- Статусы: created → pending → succeeded/failed

## 10) План разработки
- **MVP (3–4 недели):** лендинг, карта-демо, калькулятор, заказ, кабинет, заглушка оплаты.
- **v1 (5–6 недель):** полноценная карта, платежи, генерация PDF, админка.
- **v2 (8+ недель):** расширенная аналитика, интеграции Telegram, подписки, поиск по архивам.

## 11) Технологический стек
**Бюджетный:** Next.js + Prisma + PostgreSQL, Vercel/Render, карты (Yandex), оплата (ЮKassa).
**Идеальный:** Next.js + NestJS, PostgreSQL + Redis, карты (Yandex/Mapbox), платежи (ЮKassa + CloudPayments), PDF (Puppeteer), S3.
